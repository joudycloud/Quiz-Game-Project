# 🔬 Science Quiz Game (Java Console Application)

An interactive, terminal-based trivia game built in **Java** that tests your knowledge across core scientific disciplines: **Physics** and **Biology**.

---

## 🚀 Features

* **Category Selection:** Choose between Physics and Biology before starting the quiz.
* **Interactive Score Tracking:** Keeps score of correct and incorrect answers in real time.
* **Instant Feedback:** Receive immediate notifications on whether your answer was correct along with explanations.
* **Clean Single-File Architecture:** Self-contained game loop, question bank, and scoring logic housed cleanly in `Main.java` for easy setup and readability.

---

## 🛠️ Technologies Used

* **Language:** Java (JDK 8 or higher)
* **Interface:** Command-Line Interface (CLI) / Standard Console I/O
